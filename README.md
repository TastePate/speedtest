# Замер скорости интернета

Консольный скрипт на Python: принимает URL, выполняет **10 последовательных запросов**, полностью скачивает каждый ответ, выводит среднее время запроса, общий объём данных и скорость.

## Запуск

Нужен Python 3.9 или новее. Сторонние зависимости отсутствуют.

```bash
git clone https://github.com/TastePate/internet-speed-meter.git
cd internet-speed-meter
python speed_meter.py "https://example.com/large-image.jpg"
```

Замените пример адреса прямой ссылкой на доступную большую картинку или файл.

При необходимости укажите таймаут сетевой операции:

```bash
python speed_meter.py "https://example.com/large-image.jpg" --timeout 60
```

Адрес `example.com/large-image.jpg` — шаблон, а не тестовый файл.

## Расчёт

Для каждого запроса `time.perf_counter()` измеряет время от начала подключения до полного чтения тела ответа. Данные читаются блоками по 64 КиБ и не сохраняются на диск. Объём считается по фактически прочитанным байтам, без HTTP-заголовков.

- Среднее время = сумма времени десяти запросов / 10.
- Скорость в МБ/с = общий объём в байтах / сумма времени / 1 000 000.
- Скорость в Мбит/с = скорость в МБ/с × 8.

Это скорость скачивания с выбранного сервера. На неё влияют сервер, маршрут, DNS и установка соединения; она может отличаться от максимальной скорости тарифа. Каждый запрос создаёт новое соединение. Скрипт просит сервер не сжимать и не отдавать кешированный ответ; сервер может игнорировать эти заголовки.

При ошибке HTTP, подключения, таймауте или неполном ответе скрипт прекращает замер с кодом 1, без итогового результата по неполной серии. Таймаут относится к отдельной сетевой операции, а не ко всей серии. Перенаправления обрабатываются стандартной библиотекой и могут добавлять HTTP-запросы.

## Проверка

```bash
python -m unittest -v
```

Тесты запускают локальный HTTP-сервер и проверяют десять последовательных скачиваний, объём данных, расчёт скорости, ошибки HTTP и оборванный ответ. Внешний интернет для тестов не нужен.

## Публикация на GitHub

Если запускаете проект из скачанного архива, создайте пустой публичный репозиторий `internet-speed-meter` в своём аккаунте и выполните из папки проекта:

```bash
git init -b main
git add .
git commit -m "Add internet speed meter"
git remote add origin https://github.com/TastePate/internet-speed-meter.git
git push -u origin main
```

При другом имени аккаунта замените `TastePate` в URL. Ссылка в инструкции клонирования предполагает публикацию под этим именем; архив сам по себе не создаёт репозиторий.
